## 3. 踩坑记录（可写进报告"问题与解决"一节）

- **现象 1（引脚选错）**：按说明应把 **PB8 / PB9** 配成 GPIO 输出，实际操作时点成了 **PA8 / PA9**（PB/PA 看混），而且参数全对（开漏 + 上拉 + 高速），运行时不会报错，只会"接线对不上"。
- **影响**：软件 I2C 任意 GPIO 都能模拟，但 ①引脚与参考驱动 `4针脚I2C版本`（PB8/PB9）不一致，接线图和代码注释对不上；②PB8/PB9 正好是 **I2C1 的 remap 引脚**，以后要切硬件 I2C 只需改一处复用配置；③PA9/PA10 是 USART1 的 TX/RX，后面串口实验容易冲突。
- **解决**：引脚图上点 PA8/PA9 → `Reset_State` 解除，再点 PB8/PB9 选 `GPIO_Output`，并在 `System Core → GPIO` 补 `Output Open Drain`、`Pull-up`、`High`。
- **现象 2（工程名）**：Project Name 首次写成 `task1_1`，生成的目录/工程文件都带 `_1` 后缀。改为 `task1` 后重新生成即可。
- **参考图**：`07`、`08`（错误状态）与 `09`、`10`（正确状态）。
